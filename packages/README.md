# Shared application packages

Reusable modules shared across Toolboxed applications and services.

- `ui/` — shared interface components
- `bim-model/` — central building model and BIM entities
- `geometry/` — geometry, drawing, and spatial utilities
- `collaboration/` — comments, presence, permissions, and activity
- `coordination/` — clash detection and system coordination
- `data-access/` — database, storage, and API access
