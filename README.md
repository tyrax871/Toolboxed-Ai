# Toolboxed

Toolboxed is a collaborative Building Information Modeling (BIM) platform for planning, designing, coordinating, documenting, approving, and constructing property.

The central building model is the source of truth. Architecture plans, specialist systems, documentation, approvals, and construction workflows connect to that model.

## Repository structure

- `app/` — application entry points
- `packages/` — shared application packages
- `docs/` — product, UX/UI, and technical documentation
- `design/` — wireframes and design-system resources
- `services/` — backend and background services
- `infrastructure/` — database and deployment configuration
- `tests/` — automated tests
- `scripts/` — development utilities
- `.github/` — GitHub workflows and project configuration
